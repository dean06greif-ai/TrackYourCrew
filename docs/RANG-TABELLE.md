Werte = **bester Wochenwert** (gedeckelt aufs eigene Wochenziel, wie bisher).
Prinzip:
- **E** erreicht man mit den Start-Vorschlägen (5 km / 150 / 20, +5 %) in **Woche 3**.
- Danach werden die Abstände immer größer (jede Stufe ≈ 1,6–1,8× die vorige).
- **S+ = Elite**: Wochenumfänge, wie sie nur Leistungssportler bzw. absolute Spitzen-Hobbyathleten
  schaffen. Zum Vergleich steht in der letzten Spalte, wer so viel macht.

## Varianten mit Zusatzgewicht (Faktor auf alle Schwellen)

| Zusatz | Faktor | Beispiel Liegestütze: E / S+ |
|---|---|---|
| ohne | 100 % | 165 / 4.000 |
| +5 kg | 80 % | 132 / 3.200 |
| +10 kg | 60 % | 99 / 2.400 |
| +20 kg | 40 % | 66 / 1.600 |
| +30 kg und mehr | 30 % | 50 / 1.200 |

Gewicht wird aus dem Varianten-Feld gelesen (z. B. „+10 kg“, „10kg Weste“). Andere Varianten
ohne Zahl (z. B. „einbeinig“) bekommen pauschal 60 % (✅ Dean, 2026-11-24). Der Faktor gilt für alle
Stufen inklusive S+. Zwischen den Gewichtsstufen wird linear gerechnet (+7,5 kg = 70 %); lbs werden umgerechnet.

## Was sich für bestehende Nutzer ändert
Ränge sind reine Anzeige aus dem Bestwert, es gehen keine Daten verloren. Wer bisher z. B. bei
Liegestützen auf C war (600), steht nach der neuen Tabelle auch auf **C** (500–850). Die mittleren
Stufen bleiben ähnlich, unten wird es leichter, oben (A/S/S+) schwerer: Wer knapp über einer
alten A- oder S-Grenze lag, kann eine Stufe tiefer landen (z. B. alt A mit 1.300 → neu B).
Damit nach der Umstellung nicht alle gleichzeitig „Rang-Up“-Meldungen bekommen, wird beim ersten
Laden nur der neue Stand gemerkt.
