# TrackYourCrew – Frontend

React 19 mit Vite, Tailwind und framer-motion. Überblick und Regeln: `../CLAUDE.md`.

| Befehl | Zweck |
|---|---|
| `npm start` | Entwicklungs-Server (Port aus `PORT`, Standard 3000) |
| `npm run build` | Produktions-Build nach `build/` |
| `npm test` | Tests (Vitest) |
| `npm run lint` | ESLint |

Umgebungsvariable `REACT_APP_BACKEND_URL` (Adresse der API), siehe `.env.example`.
